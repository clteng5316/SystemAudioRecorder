# Third-Party Notices

SystemAudioRecorder 2.0-beta.1 does not bundle third-party binaries in this source archive.

## FFmpeg

The application may launch an external `ffmpeg.exe` for MP3 conversion and as a helper for URL media processing. SystemAudioRecorder does not link to FFmpeg libraries. FFmpeg is a separate project and is governed by the license of the build you obtain.

## yt-dlp

The application may launch an external `yt-dlp.exe` for optional URL media retrieval. SystemAudioRecorder does not incorporate yt-dlp source code. yt-dlp remains a separate project under its own license.

Review the exact licenses of any binaries you redistribute.
